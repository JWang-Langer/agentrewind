# 同类方案对比与取舍

评审与用户都会问同一句话："这跟现有的 trace / 可观测性工具、跟 LangGraph 的 time travel 有什么区别？"
本文逐项给出事实性对比，并明确**我们不做什么**——边界清楚比覆盖面大更重要。

---

## 一、对比表

| 维度 | AgentRewind | LangSmith / Langfuse | OpenTelemetry GenAI 语义约定 | LangGraph checkpoint / time travel | 录制回放型 mock（VCR 类库） |
|---|---|---|---|---|---|
| 定位 | 确定性**重放**引擎 | 观测与调试平台 | 遥测标准 | 图执行状态恢复 | 测试替身 |
| 把一次运行重跑成同一结果 | ✅ 逐位一致（返回录制响应） | ❌ | ❌ | ⚠️ 从检查点恢复，但 LLM 会**重新采样** | ✅（仅限被拦截的调用） |
| 重放是否需要重新调用上游 | ❌ 零调用 | 不适用 | 不适用 | ✅ 会重新调用 | ❌ 零调用 |
| 首个分歧步的精确定位 | ✅ 指纹级 + 请求级差异路径 | ⚠️ 人工比对两条 trace | ❌ | ❌ | ❌ |
| 副作用幂等 | ✅ `(name,key)` 显式录制，回放不执行 | ⚠️ 展示调用，不阻止重执行 | ⚠️ 仅打点 | ❌ 副作用会重放执行 | ✅ 需为每个副作用单独配置 |
| 分支谱系（从第 N 步分叉） | ✅ parent/seq 链表 + `arw diff` | ⚠️ 需自行组织 | ❌ | ✅ 图内 time travel | ❌ |
| 框架绑定 | 无（任何 OpenAI 兼容上游） | 各厂商 SDK | 各厂商 SDK | 绑定 LangGraph | 绑定被 patch 的函数 |
| 数据落地 | 本地 SQLite，单文件，可离线 | SaaS / 自建服务 | 需后端 | 图状态存储 | 无 |
| CI 门禁 | ✅ `arw verify` 返回退出码 | ❌ | ❌ | ⚠️ 需自研 | ✅ |

图例：✅ 原生支持　⚠️ 部分/需自研　❌ 不提供

## 二、我们**不做**什么（刻意）

1. **不做可视化大盘**。那是观测层的职责，且已经做得很好（Langfuse 等）。
   AgentRewind 的输出是**可进 CI 的退出码**与可 diff 的结构化报告。
2. **不做多租户服务端**。本地优先：一个 SQLite 文件，`cp` 即迁移，离线可用。
3. **不做自动 monkeypatch**。副作用边界必须显式（见 [design-notes](design-notes.md) 决策 4）。
4. **不做模型评测**。它消费评测工具（可以），但它不是评测框架。

---

## 三、为什么"逐位一致"是可行的，而"重放整个 Agent"不是

关键区分：

- **重放 Agent 的全部计算**（含工具内部逻辑、时间戳、随机数）——不可行，也没必要；
- **重放 LLM 交互边界 + 外部副作用边界**——可行，且足够。

Agent 的代码本身是确定的（同一份代码 + 同一串输入 ⇒ 同一串输出），
不确定的只有两类边界：**LLM 采样**与**外部副作用**。
把这两类边界的输入输出录制下来、并在回放时按指纹复用，整个 Agent 就变成确定的。

这带来一个可验证的强断言（也是本项目的核心测试）：

```
同一份 Agent 代码 + 回放  ⇒  零上游调用 + 结果与录制逐位一致
```

本项目用**带随机 nonce 的 stub 上游**来验证这一点：
如果回放偷偷重新采样，nonce 必然变化。这比"断言函数被调用过"强得多——
后者在缓存/重试/并发等场景下会产生假阳性。

---

## 四、与"确定性执行"生态的关系

- 与 **LLM 网关/缓存层**（如语义缓存）**不是**同一类：缓存按语义相似度命中，目标是省钱；
  指纹按字节精确命中，目标是**可复现**。混用会导致"看起来命中、其实换了答案"。
- 与 **replay-based testing**（VCR / Polly.js）思路同源，但差异在**键的设计**：
  它们用"请求 URL + 方法"或调用序号，我们用**语义完备的请求指纹**（含 tools/temperature/多模态字段），
  因而能在"改了 prompt 的哪一行"这个粒度上定位分歧。
- 与 **CRDT / 事件溯源**的思想相邻：我们的 `steps` 就是 Agent 运行的事件流，
  `rewind` 是"从事件流某个位置起开辟新分支"。

---

## 五、结论（一句话）

观测工具回答"**发生了什么**"；AgentRewind 回答"**再跑一次还会不会一样，不一样是从哪一步开始不一样**"。
前者是账本，后者是版本控制。
