## 三、演示视频分镜（建议 ≤5 分钟，1080p）

原则：**全部画面来自真实终端运行**，不剪辑伪造、不用生成的假画面。

| 镜头 | 画面 | 旁白要点 |
|---|---|---|
| 1（0:00–0:30） | 问题陈述：终端里回放失败 + 报"共 1 处差异" | Agent 的 bug 为什么复现不了 |
| 2（0:30–1:20） | `python examples/run_demo.py` 第 0 段：record，显示上游被真实调用 2 次与结果 nonce | 先录一次真实运行 |
| 3（1:20–2:10） | 第 1 段：replay，显示"命中 2 次 / 上游新增调用 0 次"，且 nonce **完全相同** | 这就是确定性：没碰网络，结果逐位一致 |
| 4（2:10–2:50） | 第 2 段：`verify` 退出码 0；改 system prompt 后退出码 3 | 它可以当 CI 门禁 |
| 5（2:50–3:40） | 第 3 段：`rewind --set second_note=...`，显示 seq=3 分叉、真实重跑 1 次 | 回退到某一步改一改，从那里真跑 |
| 6（3:40–4:20） | 第 4/5 段：`diff` 与 `why`，高亮 `messages[3].content` 差异路径 | 精确定位到具体字段 |
| 7（4:20–5:00） | 第 6 段 `list`/`show` 的谱系 + 一句总结 | 观测工具答"发生了什么"，它答"再跑一次会不会一样" |

录制要点：终端字号 ≥16pt；先跑一次确保 stub 端口无冲突；把 `examples/run_demo.py` 的输出
（含 nonce 一致性）完整留在画面里，**不要遮挡随机编号**——那正是可信度所在。

**录制用命令**（视频友好模式：隐藏原始 JSON、精简命令显示、关键结论后自动停顿）：

```bash
./.venv/Scripts/python.exe examples/run_demo.py --video --pause 2
# --pause <秒>：每条关键结论后的停顿，便于配音；默认 1.5 秒
```

对比：不加 `--video` 时是完整模式（回显每个命令的原始 `--json` 输出），用于排查与评审复核。
